АРХІТЕКТУРА

Як працює FlowSpace

Цей проєкт демонструє принцип односторінкового застосунку (SPA) та відмінності від багатосторінкової архітектури (MPA).

MPA

Багатосторінковий додаток

  • Кожен перехід запитує новий HTML-документ.
  • Браузер повторно завантажує сторінку.
  • Стан JavaScript зазвичай скидається.
  • Підходить для сайтів із незалежними сторінками.
SPA

Односторінковий додаток

  • Базовий HTML завантажується один раз.
  • JavaScript змінює видимий вміст.
  • Глобальний стан зберігається між переходами.
  • Підходить для інтерактивних вебзастосунків.
i

Що перевірити?

Відкрийте DevTools клавішею F12, перейдіть у вкладку Network, виберіть тип Doc та перемикайте розділи. Нові запити за HTML-документами не повинні з'являтися.
